# AI use disclosure

## Development assistance

OpenAI Codex was used to read and interpret the assessment, review earlier context supplied by the candidate, inspect Qawafel's public product pages, write and revise code and documentation, generate a reproducible fictional dataset, and execute validation and application checks.

An earlier ChatGPT conversation supplied candidate background and planning suggestions. Those suggestions were treated as unverified context and compared with the assessment. The earlier ChatGPT model is unknown. The submission does not make claims about the candidate's experience based solely on that context.

The synthetic dataset is generated by seeded Python code, not copied from a business or generated by a financial-data service. No real company/customer records or bank credentials were used.

## AI inside the application

Isolation Forest from scikit-learn is an actual unsupervised machine-learning component. It fits a collection of random partitioning trees to the current invoice cohort; records isolated in fewer partitions tend to look unusual. Inputs are log gross amount, log amount relative to the customer's median, payment terms, and observed lateness. For settled invoices, lateness stops at payment; for unpaid invoices, it stops at the review snapshot. A not-yet-due invoice has zero observed lateness.

The model has 100 trees, a fixed random seed of 42, and illustrative contamination of 0.05. That setting controls the review threshold; it is not an estimated probability of fraud/default and has no relation to the assessment's 3% bank-status error rate. Scores are relative to each file; do not compare them across independently fitted uploads.

Fewer than 30 invoices or fewer than three distinct feature profiles skips the model and explains why. Financial calculations remain available. The model does not change, remove, or correct source invoices.

This prototype has no labels for fraud or default, so it makes no predictive-accuracy claim. Tests check repeatability, valid scores, no mutation of financial data, small-cohort behavior, and sensitivity to a deliberately extreme synthetic amount. These checks are not model validation for lending. Context hints describe amounts/terms/lateness and are not feature attribution or causal explanations.

All monetary metrics and the narrative summary are deterministic Python calculations/templates. They are not LLM-generated statements. There is no LLM runtime, prompt-to-bank integration, or external AI API call. Flags require human verification and never issue financing approval or rejection.
